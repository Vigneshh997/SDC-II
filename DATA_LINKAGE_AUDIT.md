# Clinical linkage and availability audit

31 October 2026. This is a source-documentation and local-contract audit, not a claim that restricted patient records were inspected. The user has no approved PhysioNet/Stanford access. Counts of eligible linked examinations remain unknown. Existing NIH and open ED-demo records are separate populations and must never be paired.

## Prediction boundary

Proposed task: support interpretation of an acquired frontal CXR using only information available by image acquisition time t0. An abnormality label may be assigned later as the supervised target; it must never be copied into model inputs. Report findings/impression belong to target annotation or a separately labeled retrospective task. Order-time diagnosis history is admissible only when its prior availability and intended clinical use are documented; availability does not by itself eliminate confounding.

## Proposed deterministic linkage procedure (not yet executed)

1. Pin releases and permitted use; preserve original IDs as strings. Build one row per CXR study, link dicom IDs and report path, and enforce all images agree on subject/study and time. Preserve raw date/time strings; parse fractional StudyTime correctly, with no invented precision. Do not order studies numerically by random study_id.
2. Join studies to ED stays on subject_id and require intime <= t0 < outtime. A missing or ambiguous match is an exclusion. If using an inpatient task, define its separate admission interval rather than silently expanding the ED window. Verify hadm_id when present; never require it for all ED visits.
3. For each configured numerical variable choose the last valid measured value in [t0−6 hours, t0] in the uniquely matched stay. Six hours is a **proposed protocol choice**, to be frozen before outcomes and compared with a prespecified 2-hour sensitivity window. Where an availability/store time exists, also require it <= t0. If unavailable, record that limitation rather than interpreting charttime as proof of availability.
4. Use an original timestamped pre-imaging indication/order note when feasible. Quarantine untimed triage or report-section proxies from the primary strict-timing cohort; permit only a separately labeled sensitivity cohort after human review of the timing assumption. Do not set note_available_before_prediction=true merely because the field is called History or Indication.
5. Derive age through documented source rules; MIMIC age is deidentified/anchor-based and very old ages may be capped, not exact birthdays. Respect field units and limits; ED temperature is documented in Fahrenheit with possible misdocumented Celsius. Use explicit unit evidence and exclude ambiguous entries; do not silently auto-correct every plausible number.
6. Exclude post-discharge ICD diagnoses, disposition, death status, future labs/treatments and report results from input features. Billing diagnosis is not interchangeable with image disease truth. Radiology labels may be weakly report-derived if the report remains strictly outcome-only and independence from the supplied input section is reviewed.
7. Keep one eligible study and one deterministically selected frontal view per patient for current v2 InfoNCE. Select before outcome-based balancing. Preserve official partitions where applicable; audit patient, image-hash and study disjointness. Repeated studies remain excluded until a reviewed repeated-patient sampler/loss exists.

## Required retained evidence

Private linkage table: dataset versions, patient/study/image/stay keys, original source files/hashes, acquisition time, each feature's measurement and availability time, selected note section/source/time, units, target origin and independent review decision. Record rejection reasons (no key, no unique interval, untimed note, future-only measurement, missing label, duplicate image, invalid units). Public output should expose aggregate counts and attrition by split/site/sex/age, never clinical text or linkage identifiers.

The existing loader checks matching declarations, not real timestamps or source truth. A nonempty provenance review file is a gate, not automatic certification. No source-specific converter should populate assertions until this linkage evidence exists.

For a source where targets are extracted from radiology text, audit the actual labeler's input sections. Merely renaming the input section to Indication does not make targets independent if that indication was also consumed by the labeler. Retain the exact extraction boundaries and annotation version, or obtain independently reviewed image targets. Separate sections from a finalized report are not automatically independent evidence.
